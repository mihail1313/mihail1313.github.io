Гидравлика 0.3 — инструкция пользователя

Калькулятор определяет проектные расходы теплоносителя, скорости в трубах, потери давления по веткам и общим магистралям, диктующее кольцо и расчётную точку для подбора насоса. Данные можно вводить вручную, загружать из Excel/CSV или открывать как проект JSON.

1. С чего начать

  1. Распакуйте весь архив в постоянную папку. Установите Python 3.11–3.14 с pip и Tcl/Tk, если установщик сообщает об их отсутствии.
  2. Запустите Install.cmd и дождитесь окончания установки. Интернет нужен для установки библиотек. Для дальнейших расчётов соединение с интернетом не требуется.
  3. Откройте Launch.cmd или ярлык Heating Calculator. На Windows расширение .cmd может быть скрыто: файлы видны как Install и Launch.
  4. Нажмите «Пример», затем «Рассчитать». Ознакомьтесь с вкладкой «5. Результаты» и кнопкой «Экспорт в Excel».
  5. Для собственного расчёта нажмите «Новый». Рабочий проект сохраняйте через «Сохранить как…» в отдельный JSON.

При обновлении сохраните JSON из прежней версии, установите новую версию в отдельную папку и откройте этот JSON. Сами папки приложения после установки лучше не перемещать: ярлык указывает на выбранное место.

Кнопка «Инструкция» открывает это руководство внутри приложения. Кнопка «Формулы и СП» открывает отдельный справочник с формулами, единицами и нормативными ориентирами. В окне справки можно искать нужное слово. Оба раздела работают без интернета. Файл ИНСТРУКЦИЯ.html удобно открывать обычным браузером и печатать, в том числе в PDF. Если названия вкладок не помещаются по ширине, откройте нужную через меню «Разделы».

2. Что означают система, коллектор, ветка и участок

Система в этом калькуляторе — отдельный расчётный насосный контур с общей расчётной температурой подачи/обратки и одним теплоносителем. Его номер может совпадать с пользовательским номером в Revit, но гидравлическую схему нужно проверить отдельно.

Коллектор — группа веток внутри системы. Одинаковый номер коллектора допустим в разных системах: результаты группируются по сочетанию системы и коллектора. Для собственного сопротивления коллектора добавьте отдельные участки по его паспорту; одного номера коллектора недостаточно для учёта потерь.

Ветка — путь одного потребителя или последовательной группы потребителей с одним расчётным расходом. Её длина включает подачу и обратку. Разделяйте параллельные потребители на отдельные ветки, а общий для них трубопровод вводите как магистраль.

Участок ветки — часть пути с неизменным внутренним диаметром и одним расходом. Несколько участков одной ветки суммируются. Если вдоль трубы расход меняется из-за ответвлений, эта труба не может быть одной строкой с одним расходом.

Магистраль — общий для нескольких веток участок, например насос → коллектор, участок общего обратного трубопровода, фильтр или теплообменник в общем пути. Для каждой ветки задаётся список магистралей, через которые проходит её вода.

Номера веток и ID участков должны быть уникальными во всём проекте. Если в разных системах есть одинаковые номера веток, добавьте префикс, например 1.1/101-1 и 1.2/101-1.

3. Расход: на систему или на всё здание

Для подбора насоса нужен расход того контура, который обслуживает этот насос. Внутри системы калькулятор складывает расходы параллельных веток. Подача и обратка одной ветки проводят один и тот же поток: расход не удваивают.

Примеры:

  • Один насос обслуживает две радиаторные гребёнки с одним температурным графиком: это одна система с двумя коллекторами. Расход насоса равен сумме расходов их веток.
  • Радиаторы и тёплый пол имеют собственные насосы и разные температуры: заведите две системы. Для каждой получите свой расход, потери и диктующее кольцо.
  • Один котёл питает первичный контур, теплообменник или гидравлический разделитель: первичный контур рассчитывается по собственной схеме и температурному перепаду. Сумма расходов вторичных насосов сама по себе не задаёт расход первичного насоса.
  • Общие магистрали, смесительные узлы, разные температурные графики и несколько насосов в связанном контуре требуют отдельной схемы расчёта. Приложение не решает автоматически взаимодействие насосов и смешение потоков.

Общая сумма по нескольким независимым системам полезна как справочная величина для здания. Для выбора единственного насоса её используют только при подтверждённой общей гидравлической схеме. Суммировать напоры независимых систем или параллельных веток нельзя.

4. Заполнение вкладки «1. Системы»

Выделите систему и нажмите «Изменить»; для дополнительной системы — «Добавить».

  • Номер: например 1.1. Название: например «Радиаторы, насосная группа 1».
  • Подача и обратка: расчётные температуры в °C. Подача должна быть горячее обратки; допустимая разность для расчёта начинается с 0,1 °C.
  • «Вода — автоматически по температуре»: программа использует среднюю температуру между подачей и обраткой и обновляет свойства воды. Диапазон таблицы средней температуры — 5–95 °C.
  • «Свойства введены вручную»: введите плотность, теплоёмкость и кинематическую вязкость по данным жидкости при расчётной температуре. Для антифриза нужна информация о типе и концентрации смеси; её автоматического расчёта здесь нет.
  • Запас расхода и запас напора: при положительном запасе расхода программа заново считает потери при увеличенном расходе. Только после этого применяется запас напора. Значения запасов выбирает проектировщик; универсальных обязательных процентов программа не назначает.
  • Контроль скорости: ваш порог для замечаний. Значение 1 м/с по умолчанию не является универсальным нормативным пределом.

Не используйте температуры «по привычке»: при меньшем перепаде для той же мощности нужен больший расход, следовательно, изменятся скорость и потери давления.

5. Заполнение вкладки «2. Ветки»

Нажмите «Добавить» и заполните:

  • Уникальный номер ветки, например 101-1.
  • Номер системы, например 1.1.
  • Номер коллектора, например 101.
  • Название/прибор, например «Радиатор комнаты 1».
  • Расчётную мощность ветки в Вт. Для последовательной группы приборов это суммарная передаваемая мощность.
  • ID магистралей полного пути через точку с запятой. Их удобно заполнить после создания магистралей: например М1-П;М2-П;М2-О;М1-О.

Нагрузку ветки вводят один раз. Не умножайте её на число строк труб. Паспортная мощность радиатора при 75/65/20 или 95/85/20 не обязательно равна мощности при вашем графике и не заменяет расчёт теплопотерь помещения. Введите согласованную расчётную нагрузку и отдельно проверьте возможность выбранного прибора её обеспечить.

Поле «Учтён весь путь насоса и все сопротивления» отмечайте после заполнения участков и маршрута. Оно подтверждает проверку исходных данных пользователем. Физическую связность коннекторов Revit калькулятор не проверяет.

6. Вкладка «3. Участки веток»: длина, диаметр, сопротивления

Одна строка описывает часть выбранной ветки. Задайте ID участка и номер ветки, затем длину, внутренний диаметр и сопротивления.

Длина. Если подача 12 м и обратка 11 м, в строке одинакового диаметра можно указать 23 м. Второй раз удваивать эту длину не нужно. При разных диаметрах или разных свойствах создайте отдельные строки. Фактическую длину труб отделяйте от сопротивлений арматуры и фасонных деталей.

Внутренний диаметр. Расчёт использует проходное сечение трубы. Поле Revit «Диаметр», DN и наружный диаметр могут означать другое. Для трубы 16×2,2 мм геометрическое значение составляет 11,6 мм; подтвердите размеры конкретного изделия по сортаменту.

Шероховатость. Задаётся в мм по материалу и состоянию трубы. Начальные 0,007 мм — настройка ввода, которую нужно проверить для выбранной трубы.

КМС. Введите сумму коэффициентов местных сопротивлений, относящихся к скорости именно этой строки. Для переходов, тройников и другой арматуры используйте правильное опорное сечение и паспортные/расчётные коэффициенты. Количество фитингов само по себе не является значением КМС.

Kv. Значение в м³/ч относится к одному изделию и его конкретной настройке. Паспортное Kvs полностью открытого клапана не всегда соответствует рабочему Kv. Несколько последовательных клапанов вводите отдельными строками с длиной 0; каждому задайте свой Kv и относящийся к нему диаметр.

Другие потери. Если паспорт задаёт потери в Па при вашем расчётном расходе, укажите их отдельным значением. Радиатор, фильтр, котёл, теплообменник и коллектор не получают потери автоматически только по названию.

Одно сопротивление учитывайте одним способом: через КМС, Kv или дополнительные потери. Если уже задана суммарная паспортная потеря узла, составляющие этого же узла повторно добавлять не нужно.

Режим дополнительных потерь:

  • «Известны только при проектном расходе»: базовый расчёт возможен, но напор с увеличенным расходом определить нельзя без характеристики изделия.
  • «Пропорциональны квадрату расхода»: используйте, только если такая зависимость обоснована. Дополнительная потеря тогда увеличивается в квадрате множителя расхода.

Массовое заполнение: выделите нужные строки с Ctrl/Shift → «Изменить выбранные…». Можно задать одинаковый внутренний диаметр, шероховатость или КМС. Значение применяется к каждой выбранной строке: одна и та же суммарная КМС всей ветки, внесённая во все её строки, многократно завысит потери.

После изменения участков полноту соответствующей ветки нужно проверить и подтвердить повторно. Черновик с нулевой мощностью или диаметром можно сохранить и экспортировать как исходные данные; для численного расчёта пропуски необходимо заполнить.

7. Вкладка «4. Магистрали»: как учесть весь путь

Потери полного кольца складываются из потерь ветки и общих участков её маршрута:

Δp кольца = Δp подводки/ветки + Σ Δp магистралей её пути

В обе части должны попасть подача, обратка и соответствующее оборудование от напорного до всасывающего патрубка выбранного насоса. Сам насос в список сопротивлений не добавляется. Высота здания к напору замкнутой циркуляционной системы не прибавляется; давление заполнения и расширительный бак проверяются отдельно.

Пример для двух веток одного коллектора:

  1. Создайте магистраль М-П: насос → коллектор, подающий участок.
  2. Создайте магистраль М-О: коллектор → насос, обратный участок.
  3. В обеих ветках укажите маршрут М-П;М-О.
  4. Калькулятор посчитает каждую магистраль при сумме расходов этих двух веток.
  5. В потери полного кольца каждой ветки попадут потери М-П и М-О один раз. Потери другой параллельной ветки к этому кольцу не прибавляются.

Если от общей трубы отходят разные коллекторы, разделите её в местах ответвлений. Например, общий участок обслуживает все ветки, а участок до второго коллектора — только его ветки. В списке маршрута каждой ветки должны быть ровно те участки, через которые проходит её поток.

Общий участок создавайте единственной записью и ссылайтесь на его ID из всех обслуживаемых веток. Его копии с другими ID программа посчитает разными физическими участками. Не вводите тот же кусок трубы одновременно в магистраль и в подводку ветки.

Сопротивление общего фильтра, котла или теплообменника можно описать отдельной магистралью длиной 0, включённой в необходимые маршруты. Для коллекторов с разным сопротивлением отдельных отводов учитывайте паспортные данные каждого пути.

У каждой ветки проверьте список магистралей и поставьте подтверждение полноты. Наличие галочки не может обнаружить забытое оборудование или потребителя. Неиспользуемая магистраль, введённая в систему, требует проверки: она препятствует выдаче окончательного напора системы.

8. Импорт из Excel, CSV и ведомостей Revit

Самый простой входной формат создаёт кнопка «Шаблон Excel». Это книга для веток и их участков. Общие магистрали задаются в приложении отдельно. Для продолжения работы над всем проектом предпочтителен JSON.

Порядок импорта:

  1. Сохраните исходный Excel. Если в книге есть формулы, пересчитайте её в Excel и сохраните заново.
  2. Нажмите «Импорт Excel / CSV», выберите файл и нужный лист.
  3. Проверьте смысл мощности: общая мощность строки либо мощность одного прибора, умножаемая на его количество. Для сводного шаблона повторяется общая мощность ветки.
  4. Нажмите «Проверить файл». Просмотрите количество добавляемых и удаляемых участков, общую длину и замечания.
  5. Нажмите «Применить импорт». При необходимости используйте «Отменить».
  6. Проверьте температуры систем, внутренние диаметры, мощности, сопротивления и магистрали. Сохраните JSON.

Форматы: XLSX; CSV/TSV/TXT с разделителями. Поддерживаются UTF-8, Windows-1251 и UTF-16 с BOM. Старый двоичный XLS сначала сохраните как XLSX. Номера 1.1, 101-1 и подобные храните в Excel как текст, чтобы Excel не превратил их в даты.

Колонки шаблона: номер системы, коллектора, ветки; наименование; мощность; длина; внутренний диаметр; шероховатость; КМС; Kv; дополнительные потери; устойчивый ID участка; закон дополнительных потерь. Для закона шаблона design означает «только при проектном расходе», quadratic — подтверждённый квадратичный закон.

Мощность одной ветки в нескольких строках сводного шаблона повторяется и учитывается один раз. Разные значения в этих строках создают конфликт. Если в одной ветке несколько приборов, предварительно согласуйте их суммарную нагрузку.

В сырой ведомости Revit количество труб превращается в длину только при единицах м/мм. Штуки арматуры к метрам труб не прибавляются. Мощность одного прибора умножается на количество только в явно выбранном режиме. Не задавайте мощность трубы как дополнительную тепловую нагрузку.

Программа читает сохранённые результаты формул XLSX. Она не запускает Excel и не пересчитывает формулы книги. Если результата нет или сохранена ошибка #REF!, импорт остановится. Сохранённый, но устаревший результат сам по себе не позволяет автоматически установить ошибку — источник необходимо проверить.

Для повторной загрузки используйте устойчивые ID участков, например UniqueId/ElementId из Revit. Импорт заменяет снимок выбранного источника: исчезнувшие его участки удаляются. Ручные участки и другие источники не удаляются. Если файл перенесён или переименован, выберите прежний источник в окне импорта.

При изменении одного поля и в Excel, и в калькуляторе разными значениями программа сообщит о конфликте. Если Excel значение не менял, ручная правка сохраняется. Без устойчивого ID изменённая строка может считаться новой, и перенос её ручных свойств не гарантируется.

9. Расчёт и самая нагруженная ветка

Нажмите «Проверить данные». Двойной щелчок по замечанию открывает соответствующую запись. После исправления обязательных пропусков нажмите «Рассчитать».

На вкладке «5. Результаты» выберите нужную систему. Отдельно показаны:

  • Самая мощная ветка — наибольшая тепловая нагрузка в Вт.
  • Максимальный расход ветки — наибольший расход в м³/ч. При одном теплоносителе и температурном перепаде он соответствует наибольшей мощности.
  • Диктующее кольцо — наибольшие потери всего пути, то есть ветка плюс её магистрали. Именно этот показатель нужен для расчётного напора насоса.

Короткая ветка с мощным радиатором может иметь меньшие потери, чем длинная ветка с малым диаметром. Поэтому самая мощная ветка не обязательно диктующая. При равных максимумах перечисляются все соответствующие ветки.

Если полный путь не подтверждён, программа показывает «Максимум учтённых потерь». Это предварительный кандидат: после добавления магистралей, оборудования или потребителей диктующее кольцо может измениться. Окончательный напор насоса при неполной схеме не выдаётся.

Таблица веток разделяет потери подводки, магистрали и кольца. Длина подводки — сумма введённых труб ветки; общие магистрали и условная длина сопротивлений в неё не включаются. Отдельно доступны длина магистралей данного маршрута и полная длина труб кольца. Полные длины разных колец не суммируйте для закупки труб: они повторно включают общие участки. Для закупки суммируйте каждую физическую запись ветки/магистрали один раз.

Вкладка «По участкам» показывает расход, скорость, Re, коэффициент трения и вклад трения, КМС, Kv, дополнительных потерь. Вкладка «Коллекторы» суммирует нагрузки, расходы и длины подводок своих веток.

«Добавить балансировкой» — разность между потерями диктующего кольца и данного полного кольца при проектных расходах. Это ориентир требуемого дополнительного сопротивления, а не автоматически выбранная настройка клапана. Фактическое распределение расходов после установки оборудования здесь не моделируется.

Результат для насоса состоит из расхода в м³/ч и напора в метрах данного теплоносителя. Для выбора модели сравните эту точку с рабочими характеристиками производителя, диапазоном регулирования, ограничениями шума и применимостью жидкости.

12. Если что-то не получается

  • «Не найден Python с Tcl/Tk»: установите поддерживаемый Python с компонентом Tcl/Tk, закройте старое командное окно и запустите Install.cmd заново.
  • Окно установки остановилось: проверьте install.log рядом с программой. На этапе создания окружения вывод может некоторое время отсутствовать.
  • Launch закрывается, а приложение не появляется: проверьте журнал %LOCALAPPDATA%\HeatingCalculator\startup.log. Ошибки операций приложения записываются в error.log в той же папке.
  • Нет расчёта: нажмите «Проверить данные»; заполните мощности, внутренние диаметры и ссылки на существующие ветки/магистрали.
  • Нет окончательного напора: проверьте полный путь и всех потребителей каждой системы, назначение всех магистралей, затем подтвердите полноту. Не ставьте галочку только для получения числа.
  • Нет напора с запасом расхода: для дополнительных потерь задана только одна паспортная точка. Нужен закон изменения либо расчёт без этого запаса.
  • Не видны все столбцы: воспользуйтесь горизонтальной прокруткой таблицы или разверните окно.
  • Excel не сохраняется: закройте открытый целевой XLSX, выберите новое имя/доступную папку; прочитайте сообщение приложения.
  • После изменения данных прежние результаты исчезли: выполните «Рассчитать» повторно. Так отчёт не смешивает старые результаты с новыми исходными данными.

13. Что проверяет пользователь перед подбором насоса

Проверьте состав потребителей насосного контура, их расчётные нагрузки и температурный график; действительные внутренние диаметры; обе стороны циркуляционного пути; сопротивления приборов и оборудования; распределение расходов по общим участкам; настройки регулирующей арматуры. Нулевые КМС/дополнительные потери означают принятый ноль, а не доказанное отсутствие сопротивлений.

Программа рассчитывает заданную схему при проектных расходах. Она не определяет теплопотери помещений, не восстанавливает автоматически соединения Revit, не решает сложную многокольцевую сеть со смешением, не подбирает модель насоса и не подтверждает выполнение всех нормативных требований. Формулы и применимость нормативных документов подробно приведены в разделе «Формулы и СП».

3. Расход из тепловой нагрузки

ΔT = tп − tо
ṁ = Q / (cp × ΔT)                         [кг/с]
G = 3600 × ṁ                             [кг/ч]
V̇ = ṁ / ρ                               [м³/с]
Vh = 3600 × Q / (ρ × cp × ΔT)            [м³/ч]

Для системы с общими свойствами и температурным перепадом:

Qсистемы = Σ Qветок
Vh,системы = Σ Vh,веток
ṁмагистрали = Σ ṁветок, проходящих через эту магистраль

Подача и обратка передают один циркулирующий расход. Их расход при определении производительности насоса не суммируется дважды. Общий участок учитывает только ветки, в маршрутах которых указан его ID.

Расход рассчитывается для отдельного насосного контура. Для нескольких независимых насосных групп нужны отдельные расчётные точки. При разных ΔT нельзя без проверки заменить расчёт каждой системы формулой с общей мощностью и произвольным единым ΔT. Расход первичного контура через гидравлический разделитель/теплообменник определяется своей схемой и графиком.

4. Скорость и число Рейнольдса

Aсечения = π × d² / 4
v = V̇ / Aсечения
Re = v × d / ν

Здесь d — именно внутренний диаметр. Номинальный DN и наружный размер не подставляются автоматически. При нулевом расходе программа принимает скорость, Re и потери равными нулю.

5. Коэффициент трения Дарси

При 0 < Re < 2300 используется ламинарная зависимость:

λ = 64 / Re

При Re ≥ 2300 используется корреляция Churchill:

A = [2,457 × ln(1 / ((7 / Re)^0,9 + 0,27 × ε / d))]^16
B = (37530 / Re)^16
λ = 8 × [(8 / Re)^12 + 1 / (A + B)^1,5]^(1/12)

ln — натуральный логарифм. Для диапазона 2300 ≤ Re < 4000 выводится замечание «Переходный режим». При Re ≥ 4000 режим обозначается как турбулентный. Это инженерная корреляция для коэффициента Дарси, а не коэффициент Фаннинга; подстановка коэффициента Фаннинга без множителя 4 даст другой результат.

Справочная публикация корреляции: S. W. Churchill, «Friction-factor equation spans all fluid-flow regimes», Chemical Engineering, 84(24), 1977, pp. 91–92. Использование этой зависимости не означает автоматического соблюдения всех требований какого-либо СП.

6. Трение и местные сопротивления

Динамическое давление и удельные потери:

pдин = ρ × v² / 2                         [Па]
R = (λ / d) × pдин                       [Па/м]
Δpтр = R × L = λ × (L / d) × ρ × v² / 2 [Па]
Δpмест = Σζ × ρ × v² / 2                 [Па]

Это зависимость Дарси–Вейсбаха для трения и зависимость через КМС для местных сопротивлений. КМС должен относиться к скорости выбранного участка. Если разные изделия требуют разных опорных сечений, задайте их отдельными строками.

Длины подающей и обратной трубы включаются один раз. При разных диаметрах или расходах нужны отдельные участки, потому что v, Re и λ для них различаются.

7. Потери по Kv и паспортные потери

Для одного изделия с паспортным Kv:

ΔpKv = (Vh / Kv)² × (ρ / 1000) × 100000  [Па]

Vh и Kv задаются в м³/ч. Множитель 100000 переводит бар в Па, ρ/1000 учитывает относительную плотность жидкости. Kv должен соответствовать положению арматуры. Коррекции на высокую вязкость, кавитацию и специальный режим изделия этой формулой не выполняются; проверяйте применимость паспортных данных.

Для нескольких последовательных изделий создайте отдельные строки: их потери складываются. Несколько параллельных устройств нельзя автоматически представить этим же суммированием без схемы распределения расхода.

Дополнительные потери вводятся в Па при расчётном расходе. Например, это могут быть потери радиатора или теплообменника, уже полученные по диаграмме производителя. Закон их изменения при другом расходе задаётся отдельно, а не угадывается.

8. Сумма потерь участка, ветки и кольца

Δpучастка = Δpтр + Δpмест + ΔpKv + Δpдоп
Δpветки = Σ Δpучастков этой ветки
Δpмагистралей,ветки = Σ Δpобщих участков в маршруте ветки
Δpкольца = Δpветки + Δpмагистралей,ветки

Общие участки считаются при суммарном расходе обслуживаемых веток, затем их потери добавляются в каждое кольцо, проходящее через эти участки. Участок не копируется физически для каждого потребителя. Если одна труба ошибочно введена дважды под разными ID, она будет посчитана дважды.

Сопротивления подающей и обратной магистрали, арматуры, коллекторного узла, прибора и общего оборудования должны попасть в подходящие строки. Из названия оборудования программа не определяет его сопротивление. Одно изделие не следует учитывать одновременно через Kv и через уже включающую его паспортную потерю.

9. Нагрузка, диктующее кольцо, балансировка, напор

Самая мощная ветка:      максимум Qветки
Максимальный расход:    максимум Vh,ветки
Диктующее кольцо:       максимум Δpкольца
Δpсистемы = max(Δpкольца)
H = Δpсистемы / (ρ × g),  g = 9,80665 м/с²
Δpбалансировки,ветки = max(0; Δpсистемы − Δpкольца,ветки)

Параллельные потери не складываются. Наибольшая мощность не определяет диктующее кольцо: значение имеют длина, диаметры, арматура и общие участки пути. Все равные максимумы перечисляются; численное сравнение учитывает малую погрешность вычисления, поэтому почти равные значения после округления на экране могут различаться в исходном расчёте.

Напор и ориентир балансировки выдаются при подтверждении полного пути всех веток системы и при использовании введённых магистралей. В неполной схеме максимум относится только к учтённым участкам. Подтверждение полноты задаётся пользователем и не заменяет проверку физической схемы.

Δpбалансировки — требуемый дополнительный перепад при проектном расходе, а не фактическая настройка клапана и не расчёт установившегося распределения расходов во всей сети.

В замкнутом циркуляционном контуре статические составляющие высоты подачи и обратки компенсируются. Поэтому высота здания не добавляется к H циркуляционного насоса. Давление заполнения, прочность системы, расширительный бак и кавитационные условия требуют отдельной проверки. Для открытой системы или перекачки между резервуарами эта модель полного напора неприменима без учёта дополнительных составляющих.

10. Запасы расхода и напора

kQ = 1 + запас_расхода[%] / 100
Vh,насоса = Vh,системы × kQ
ṁ'каждой ветки = ṁветки × kQ
Δp'системы = max(Δp'колец, заново рассчитанных при увеличенных расходах)
Hнасоса = Δp'системы / (ρ × g) × (1 + запас_напора[%] / 100)

Программа повторно определяет скорости, Re, коэффициенты трения и потери труб/КМС/Kv. Поэтому потери целой сети не заменяются автоматически прежними потерями, умноженными на kQ²: в ламинарном режиме и при изменении λ зависимость иная. Диктующее кольцо при увеличенном расходе может измениться.

Для дополнительных потерь при подтверждённом квадратичном законе:

Δp'доп = Δpдоп × kQ²

Если дополнительные потери известны только при проектном расходе, базовый расчёт доступен; при kQ > 1 программа не выдаёт вымышленный напор с запасом. Нужно задать обоснованную зависимость или отказаться от увеличения расхода в этом расчёте. Запас напора при неизменном расходе может применяться к известным базовым потерям.

11. Ограничения модели

Расчёт относится к заданной сети с проектными расходами, стационарному течению и принятой несжимаемости теплоносителя. Внутри одной ветки расход одинаков во всех её строках. Разделение/объединение расходов представляется отдельными ветками и общими магистралями. Каждая система считается независимым насосным контуром.

Не выполняются: расчёт теплопотерь помещений; подбор приборов по температурным поправкам; решение многокольцевой сети с неизвестными распределениями расходов; модель взаимодействующих насосов; смешение температур; подбор настроек клапанов; выбор конкретного насоса; проверка давления заполнения, расширительного бака и всех требований строительных норм.

Численные ограничения ввода защищают от ошибочных единиц и чрезмерных значений; они не доказывают физическую применимость любого принятого числа. Например, возможность ввести температуру не доказывает существование жидкой фазы выбранного теплоносителя при рабочем давлении.
