# Гидравлика 0.2 — скачать калькулятор

[Скачать HeatingCalculator-v0.2.zip](https://raw.githubusercontent.com/mihail1313/mihail1313.github.io/calculator-download-v0.2/downloads/HeatingCalculator-v0.2.zip)

1. Распакуйте весь архив в постоянную папку на Windows.
2. Запустите `Install.cmd` и дождитесь завершения установки.
3. Откройте `Launch.cmd` или ярлык `Heating Calculator` на рабочем столе.

Для установки требуется Python 3.11–3.14 с Tcl/Tk и pip, а также интернет для загрузки зависимостей. Установщик создаёт отдельное окружение приложения.

В комплекте исходное приложение, установщик, инструкции, тесты и демонстрационный проект. Готового EXE нет; `Build_EXE.cmd` собирает его на Windows. Проверки расчётного ядра и интерфейса выполнены в Linux; установка и сборка EXE на Windows ещё не проверены.

Контрольная сумма архива: `HeatingCalculator-v0.2.zip.sha256`.
