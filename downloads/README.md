[Читать инструкцию](Manual-v0.3.md) · [Формулы и СП](Formulas-and-SP-v0.3.md)

В версии 0.3: заметный экспорт Excel, выгрузка исходных данных незавершённого проекта, сводка по каждой системе, раздельное отображение самых мощных веток и диктующих колец, потери ветки + магистралей, встроенные справки и инструкция HTML.

1. Распакуйте весь архив в постоянную папку на Windows.
2. Запустите `Install.cmd` и дождитесь завершения установки.
3. Откройте `Launch.cmd` или ярлык `Heating Calculator` на рабочем столе.

Если пользуетесь версией 0.2, сначала сохраните рабочий JSON. Новую версию распакуйте в отдельную постоянную папку, выполните Install и откройте свой JSON через «Открыть JSON». Повторная установка Python не нужна, если подходящая версия с Tcl/Tk уже установлена.

Внутри приложения нажмите «Инструкция» или «Формулы и СП». Отдельный файл `ИНСТРУКЦИЯ.html` из архива открывается в браузере без интернета и допускает печать/PDF.

Для установки требуется Python 3.11–3.14 с Tcl/Tk и pip, а также интернет для загрузки зависимостей. Установщик создаёт отдельное окружение приложения.

В комплекте исходное приложение, установщик, инструкции, тесты и демонстрационный проект. Готового EXE нет; `Build_EXE.cmd` собирает его на Windows. В Linux прошли 93 автоматических теста и 3 сценария настоящего интерфейса Tk; архив также распакован и проверен. Установка и сборка EXE на Windows здесь не выполнялись. Актуальные редакции и изменения СП необходимо сверить: официальный нормативный каталог был недоступен при подготовке справки.

Контрольная сумма архива: `HeatingCalculator-v0.3.zip.sha256`; внутри — `MANIFEST.json` с SHA-256 файлов.
